# Submission checklist — Finite Fields and Their Applications

Run `python3 -I compliance_check.py` (in this folder) after `./build.sh`; it
checks the items marked (auto).

## Manuscript
- [x] elsarticle, single column (`preprint`, 12pt), `\journal{Finite Fields and Their Applications}` (auto)
- [x] Abstract at most 250 words (auto)
- [x] 1 to 7 keywords, none with "and" / "of" (auto); 2020 MSC codes given
- [x] Title page: three authors, three affiliations with postal address and country, one corresponding author with e-mail (auto)
- [x] Numbered references, `elsarticle-num`; every bib entry cited, every citation defined (auto)
- [x] Figures supplied as separate files (`figures/`); tables are editable text
- [x] No LaTeX errors, no undefined references or citations (auto)
- [x] No template leftovers from other publishers, no placeholders (auto)

## Declarations (all inside the manuscript, before the references)

- [x] Declaration of competing interest
