## 5. Data availability

No external datasets were used. All computational data in the article are
generated by the Python code supplied as supplementary material:

* `code/enumerator.py` — the transfer-matrix enumerator, the restricted
  self-orthogonal / dual-containing / self-dual counts, and the moment formulas;
* `code/checks.py` — the complete verification, whose saved output is
  `code/checks_output.txt` (`ALL CHECKS PASSED`);
* `code/generate_tables.py` — regenerates every CSV in `tables/`;
* `code/symbolic_verification.txt` — external SymPy 1.14.0 re-derivation of
  the moment, covariance and complexity formulas.

The article's Table I, Table II, the two joint-distribution figures and all
worked examples are reproduced by this code. The shipped code uses only the
Python standard library; SymPy is an external verification tool only.
